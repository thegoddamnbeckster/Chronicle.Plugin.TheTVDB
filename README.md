# Chronicle.Plugin.TheTVDB

Metadata provider plugin for **TheTVDB**.

## Design Document

Full design documentation:
[docs/plugins/PLUGIN_THETVDB.md](https://github.com/thegoddamnbeckster/Chronicle/blob/develop/docs/plugins/PLUGIN_THETVDB.md)

## Supported Media Types

`tv`, `tv_season`, `tv_episode`

## Quick Start

1. `dotnet build`
2. Copy `Chronicle.Plugin.TheTVDB.dll` to your Chronicle `plugins/active/` directory
3. Restart Chronicle
4. Navigate to **Settings -> Plugins -> TheTVDB**
5. Configure required settings (see design doc)
